# Portal de Estudio

Portal de estudio en grupo: práctica con retroalimentación, simulacros calificados sobre 100, casos y preguntas de respuesta rápida.

- Acceso por participante, sin clave. El avance de cada uno se guarda por separado.
- Funciona en computador y en celular.

Herramienta de estudio personal. No es un sitio oficial de ninguna institución. Las preguntas son ejercicios de preparación.

Sitio: https://luisdurangf.github.io/portal-de-estudio/
